# Portifolio-GCSI

NFT preview card inspired by the [Frontend Mentor challenge](https://www.frontendmentor.io/challenges/nft-preview-card-component-SbdUL_w0U).

## GitHub Pages

The static site is deployed automatically with GitHub Actions when changes are pushed to `main` or `feat/nft-preview-card`. In the repository settings, set **Pages** to use **GitHub Actions** as the build and deployment source.
